# TaxBridge Solutions website

## Files
- `index.html` — main website
- `style.css` — layout, colours, responsive styles
- `script.js` — mobile navigation, enquiry form and WhatsApp link
- `privacy.html` — starter privacy policy template

## Run locally
1. Extract the ZIP.
2. Open the `taxbridge-solutions` folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Important setup before publishing
1. Open `script.js`.
2. Replace `91XXXXXXXXXX` in `WHATSAPP_NUMBER` with your real WhatsApp number, including country code 91 and no `+`, spaces or hyphens. Example format: `919876543210`.
3. In `index.html`, replace `hello@taxbridgesolutions.in` and the working hours with your real details.
4. Review the service list, claims and fees so they accurately match the services you can provide.
5. Customise `privacy.html` to reflect your real data handling. It is only a starter template.
6. Test all buttons, mobile layout, form validation and WhatsApp message before publishing.

## Important limitations
- The enquiry form opens WhatsApp; it does not save submissions to a server or database.
- No customer accounts, admin panel, online payments, filing-status system or secure document uploads are included.
- Do not ask customers to send passwords, OTPs, bank credentials or unnecessary sensitive identity data.
- This is an independent service-provider website. Do not imply government affiliation.
- Hosting, a domain and any backend services are separate from this static website.
